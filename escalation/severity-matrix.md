# Incident Severity Matrix (SOC Level 1)

## 🎯 Purpose
To classify security incidents based on impact and urgency for proper escalation.

---

## 🔴 Critical (P1)

- Ransomware detection
- Active data exfiltration
- Multiple system compromise
- Privilege escalation confirmed

**Action:** Immediate escalation to SOC L2/L3

---

## 🟠 High (P2)

- Malware infection on single system
- Suspicious login activity
- Firewall breach attempts
- Unauthorized access attempt

**Action:** Escalate after initial containment

---

## 🟡 Medium (P3)

- Multiple failed login attempts
- Suspicious network traffic
- Policy violations
- Unusual system behavior

**Action:** Monitor and report

---

## 🟢 Low (P4)

- Informational alerts
- Minor policy violations
- False positives
- Routine security logs

**Action:** Log and monitor
