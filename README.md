# SOC Level 1 Playbook

This repository contains real-world SOC Level 1 workflows based on enterprise Security Operations experience in an MSSP environment.

It includes incident response guides, log analysis techniques, escalation workflows, and security monitoring practices used in day-to-day SOC operations.

---

## 🔍 What This Repo Covers

- Security Incident Detection & Response
- Log Analysis (Firewall, Windows, SIEM)
- Threat Investigation Workflows
- Alert Triage & Prioritization
- Escalation Procedures (L1 → L2)

## 🧠 Incident Response Approach

1. Alert Detection (SIEM / Firewall / Endpoint)
2. Log Verification
3. Threat Validation
4. Containment Actions
5. Escalation (if required)
6. Documentation & Reporting
